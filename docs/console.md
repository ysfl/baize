# 控制台功能指南

[返回 README](../README.md)

白泽控制台把服务器、网站、安全、自动化和平台设置集中在一个界面里。本文按左侧菜单介绍每个功能能做什么、什么时候用，帮助你快速找到入口。

登录后首页是**运营总览**：汇总在线服务器、待处理提醒、网站访问质量与防护命中，异常项可以直接跳转到对应页面。

## 服务器

| 菜单 | 能做什么 | 什么时候用 |
| --- | --- | --- |
| 服务器管理 | 查看所有接入的服务器、在线状态和负载；进入详情查看指标、进程、磁盘、容器、文件与 Agent 版本 | 日常巡检、定位某台机器的问题 |
| 资产台账 | 记录服务器的归属、到期时间与备注 | 管理续费、交接 |
| 磁盘风险 | 汇总各服务器磁盘使用和增长趋势 | 提前发现磁盘将满 |
| 服务器分组 | 按业务、地区或供应商分组 | 批量查看、批量下发任务 |
| 运行诊断 | 针对单台服务器发起只读诊断，例如查看端口、进程或服务的归属 | 排查"这个端口被谁占用""这个服务为什么不在" |
| 服务管理 | 对 systemd、Nginx、Docker 服务执行启动、停止、重启、重载 | 受控地重启服务，代替手写命令 |
| 资源趋势对比 | 多台服务器的 CPU、内存、磁盘、网络趋势放在一起对比 | 判断是单机问题还是整体问题 |

在服务器详情中还可以：

- **进程风险**：查看高资源占用与可疑进程，必要时结束进程。
- **服务器文件**：浏览、预览、编辑和上传文件；写入和删除需要对应权限，并保留审计记录。
- **容器服务**：查看容器状态与资源，实时查看容器日志。
- **升级 Agent**：在详情页一键升级节点组件。

被移除的服务器进入**服务器回收站**，可以恢复或彻底删除。Agent 的安装参数与排障见 [Agent 参数与排障](agent.md)。

## 网站

| 菜单 | 能做什么 | 什么时候用 |
| --- | --- | --- |
| 网站中心 | 自动发现各服务器上的 Nginx 站点，汇总请求量、错误率与采集状态 | 查看有哪些网站、哪个网站有异常 |
| 访问分析 | 按站点查看访问量、状态码、慢请求和来源 | 分析流量变化、定位慢请求 |
| 配置发布 | 在线编辑 Nginx 配置：生成草稿、对比差异、发布前自动备份并执行 `nginx -t` 检查，失败可回滚 | 修改站点配置并保留变更记录 |

网站中心顶部会显示访问数据链路的健康状态。没有数据时先看这里：显示"数据为空"不一定代表没有访问，也可能是采集中断。

## 安全

| 菜单 | 能做什么 | 什么时候用 |
| --- | --- | --- |
| 提醒中心 | 集中查看告警，确认或解决；配置通知渠道、联系人分组、静默与升级规则 | 值班处理告警 |
| 请求风险识别 | 按请求链路识别异常访问模式 | 发现扫描、撞库等可疑请求 |
| 入口暴露风险 | 识别对公网开放的高风险端口与服务 | 收敛不必要的公网暴露 |
| 网络入口识别 | 梳理服务器的对外入口与流量路径 | 了解谁能访问到你的服务 |
| 证书到期提醒 | 监控 SSL 证书到期时间 | 避免证书过期导致网站不可访问 |
| 网站安全防护 | 网站防护的总览、规则、拦截记录、防护更新记录和安全态势大屏 | 查看是否被攻击、是否拦截成功，调整防护模式 |

网站安全防护支持**观察**与**拦截**两种模式。建议先用观察模式运行一段时间，确认没有误报后再切换为拦截。

## 自动化

| 菜单 | 能做什么 | 什么时候用 |
| --- | --- | --- |
| 执行任务 | 向一台或多台服务器下发命令，支持批量、分批与失败重试，保留输出 | 一次性运维操作、批量巡检 |
| 远程会话 | 浏览器内的终端 | 临时排障；常规变更建议用执行任务，便于审计和复盘 |
| 处置预案 | 把常用的处置步骤整理成可复用的预案 | 标准化应急处置流程 |
| 执行计划 | 基于命令模板创建、审批和执行计划 | 需要审批或高风险的变更 |
| 计划任务 | 定时在指定服务器上执行命令，支持一次性和重复计划 | 定期巡检、定时采集 |
| 执行记录 | 查看所有远程操作的审计记录：谁、何时、在哪台机器、执行了什么 | 事后追溯 |
| 运行记录 | 查看白泽自身的运行日志 | 排查平台本身的问题 |

处置预案的自动调度默认关闭（`.env` 中 `RUNBOOK_SCHEDULER_ENABLED=false`），预案需要手动执行。远程任务的风险确认与审批规则见 [AI 接入与远程任务指南](ai-remote-tasks.md)。

## 平台

| 菜单 | 能做什么 |
| --- | --- |
| 系统设置 | 平台级开关，例如直连自定义命令策略、远程方案审批开关 |
| 系统信息 | 查看中心服务运行状态与依赖组件 |
| 版本与订阅 | 查看当前版本、检测新版本并更新，查看订阅权益与激活 |
| 访问凭据 | 创建和管理 Agent 注册令牌 |
| 身份与权限 | 管理账号、角色和资源范围 |
| 智能服务配置 | 接入 AI 模型服务，用于配置建议、终端命令解释等辅助功能 |

## 遇到错误时

操作失败时，提示会说明原因和建议的下一步。各类提示的含义和处理方法见 [错误提示与处理](errors.md)。
