# 错误提示与处理

[返回 README](../README.md)

在白泽控制台、MCP 或 API 中操作失败时，白泽会告诉你失败的原因和建议的下一步。本文按你看到的提示归类，说明它的含义和处理方法。

## 先看三样东西

1. **提示文字**：说明失败原因，例如"目标服务器当前不在线"。
2. **处理建议**：提示后面附带的下一步，例如"请确认目标服务器在线，并已开启所需功能后重试"。
3. **追踪号**：每次请求都有一个唯一编号。服务端内部出错时，管理员可以用它在白泽日志中找到对应记录。

通过 API 调用时，错误响应同样带有稳定的原因代码、下一步建议和追踪号，可据此在程序里判断如何处理；MCP 会把原因代码和下一步一并返回给 AI 客户端。

## 登录与权限

| 提示 | 含义 | 处理 |
| --- | --- | --- |
| 请先登录后再继续操作 / 登录状态已过期 | 会话缺失或过期 | 重新登录。MCP 用户执行 `baize-mcp login` 后重启 AI 客户端 |
| 当前账号无权执行该操作 | 账号角色缺少这个动作的权限 | 联系管理员在「权限管理」中为账号分配对应角色 |
| 目标资源不在当前账号的授权范围内 | 权限足够，但目标服务器不在账号可管理的范围内 | 联系管理员调整账号的资源范围，或换用有该服务器范围的账号 |
| 当前版本或授权未开放该功能 | 当前订阅不包含该功能 | 在「版本与订阅」查看授权状态 |
| 请求过于频繁，请稍后再试 | 触发了频率限制 | 稍等片刻再操作；登录失败过多时账号会被暂时锁定，见[管理员密码与安全码重置](credential-reset.md) |

## 填写与提交

| 提示 | 含义 | 处理 |
| --- | --- | --- |
| 请求参数不正确，请检查输入后重试 | 提交的内容不符合要求 | 检查表单必填项和取值范围 |
| 缺少必填项「字段名」（新版本） | 指出具体缺少哪一项 | 补充该项后重试 |
| 「字段名」不能超过 N / 只能是以下取值之一（新版本） | 指出具体哪一项不合规及规则 | 按提示修改该项 |
| 提交的数据格式不正确（新版本） | 请求内容无法解析，通常是页面版本过旧 | 刷新页面后重试；通过 API 调用时检查请求体是否为合法 JSON |
| 目标资源不存在或已被删除 | 记录已被删除或编号有误 | 刷新列表确认 |
| 当前资源状态不允许执行该操作 | 对象状态已变化，例如任务已结束、计划已执行 | 刷新后查看最新状态，再决定下一步 |

标注"新版本"的提示随白泽后续版本提供，旧版本中同类问题会统一显示为"请求参数不正确"。

## 服务器与 Agent

| 提示 | 含义 | 处理 |
| --- | --- | --- |
| 目标服务器当前不在线 | Agent 未连接到白泽 | 在服务器列表确认在线状态；离线排查见 [Agent 参数与排障](agent.md#节点一直连不上) |
| 服务器连接暂时不可用 | 与 Agent 的连接短暂中断 | 稍后重试；持续出现时检查服务器网络 |
| 该服务器的组件版本不支持此功能 | Agent 版本过旧，尚未提供该能力 | 在服务器详情页升级 Agent |
| 操作等待超时 | Agent 未在预期时间内返回结果 | 先查看任务或操作记录确认是否已经生效，再决定是否重试 |

## 远程任务与命令

| 提示 | 含义 | 处理 |
| --- | --- | --- |
| 直连自定义命令策略当前为关闭状态 | 系统未开放直接执行自定义命令 | 改用命令模板或普通远程任务；需要开放时由系统所有者在「系统设置」调整策略 |
| 该命令未登记到直连执行白名单 | 策略为白名单模式且命令未登记 | 登记该命令，或改用命令模板 / 普通远程任务 |
| 当前资源状态不允许执行该操作（远程任务） | 常见于任务已结束仍取消、高风险操作缺少风险确认、上一批次尚未结束 | 先查看任务状态；高风险操作需要显式确认风险；批量任务等待上一批结束或取消卡住的目标 |
| 新任务马上失败且没有输出 | 并发额度被未结束的任务占满 | 取消卡住的任务后重试一次 |

远程任务的确认与风险边界见 [AI 接入与远程任务指南](ai-remote-tasks.md#失败处理)。

## 网站与防护

| 提示 | 含义 | 处理 |
| --- | --- | --- |
| 网站防护全局开关已关闭 | 全局关闭时只能查看、停用或回滚 | 在网站防护页开启全局开关后再修改规则 |
| 系统正在恢复应用前配置 | 上一次规则应用失败，正在自动恢复 | 等待恢复任务完成并查看结果 |
| 目标服务器的待执行任务已达到安全上限 | 该服务器排队的防护任务过多 | 等待已有任务完成后再提交 |
| 暂时无法确认这个站点对应的 Nginx 配置入口 | 同一域名可能对应多套 Nginx，白泽为避免误改而只读 | 在站点配置页刷新配置发现后重新选择 |
| 站点配置状态已变化，请刷新后重新生成草稿 | 草稿生成后服务器上的配置已被修改 | 刷新后重新生成草稿 |
| 配置检查未通过或尚未完成 | 发布前的 `nginx -t` 检查未通过 | 查看检查结果，修正后重新检查 |
| 发布前备份缺失或失败 | 发布前必须有可回滚的备份 | 先创建备份 |
| 同一站点服务正在发布配置 | 另一次发布尚未结束 | 等待当前发布结束 |

## 订阅与激活

| 提示 | 含义 | 处理 |
| --- | --- | --- |
| 激活码无效 / 已过期 / 已被撤销 / 已被使用 | 激活码状态不可用 | 在官方授权中心核对或重新生成激活码 |
| 暂时无法连接官方授权中心 | 服务器无法访问授权中心 | 确认服务器出口网络可以访问授权中心后重试 |
| 本次请求未通过授权中心签名校验 | 常见原因是服务器时钟偏差 | 校准服务器时间（NTP）后重试 |
| 当前订阅的授权配额已用尽 | 席位或节点数达到上限 | 调整订阅或联系授权中心管理员 |

## 服务暂时不可用

看到"服务暂时不可用，请稍后重试"时，表示白泽服务端内部出现了异常：

1. 稍后重试一次。
2. 仍然失败时，在白泽安装目录查看服务端日志，按追踪号搜索（新版本中服务端会为这类异常记录详细原因）：

   ```bash
   docker compose logs --tail=500 server | grep <追踪号>
   ```

3. 日志无法判断时，带上追踪号、操作步骤和出现时间，到下方渠道反馈。
